# Federation: deferred

Federation is outside Milestone 1 and all v0.1 integration work. The `protocol` package exists structurally and contains only local HTTP contracts.

No node identity, keys, well-known descriptor, peer API, discovery, relay, DHT, signatures, federation tables or public catalog is implemented. OpenFlix must first work independently with a real Jellyfin backend through milestones 2–5. See sections 62–66 of the original specification for later work. Nothing is published or shared automatically.
