# Milestone 1 local API

All API routes are OpenFlix-owned. Browser requests are same-origin and credentials remain in an HttpOnly cookie.

| Method/path                | Behavior                                                                                                                                                                                                                                                                                                     |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `GET /health`              | Public readiness: 200 `{"status":"healthy","database":"ok"}`; 503 with `unhealthy`/`unavailable` if the DB probe fails. No connector/peer claims.                                                                                                                                                            |
| `POST /api/v1/auth/login`  | JSON `{ "username": "…", "password": "…" }`, exact configured Origin required. 200 `{ "user": { "id", "username", "displayName", "role" } }` and a session cookie. 401 generic invalid credentials; 400 malformed input; 403 wrong/missing origin; 413 oversized; 429 rate limit; 503 password workers busy. |
| `GET /api/v1/me`           | 200 safe user projection for a valid unexpired session, otherwise 401.                                                                                                                                                                                                                                       |
| `POST /api/v1/auth/logout` | Exact configured Origin required. Revokes presented session, expires cookie, returns 204. Idempotent even without a session.                                                                                                                                                                                 |

No other routes are implemented. Unknown routes return 404. Errors are `{ "error": "safe message" }`; raw validation/database errors are not returned. Request IDs are generated by the server and returned in `X-Request-Id`. Responses are not cacheable.
