# Local source candidate — unreleased

- Adds artwork-led Home, movie and series details, hierarchical Back and an automatically rotating featured area.
- Uses personal Jellyfin connections with server-side encrypted credentials and automatic initial library synchronization; legacy shared connections remain quarantined.
- Adds one-time first-owner setup and keeps operator-provisioned additional users.
- Improves direct and bounded Jellyfin-managed HLS playback, including supported HDR-to-SDR negotiation, and preserves per-user resume.
- Uses a burnt-orange accent and a loopback-only local Compose configuration.

This candidate is not yet a public release or a claim of universal codec or device compatibility. Current validation includes disposable real Jellyfin and Chromium, plus limited user-directed household testing. Firefox, iPhone, TV devices, installer distribution, sustained playback and all possible media formats remain unverified. Plex, Emby, Screenroom and Live TV are future work, not supported features.
