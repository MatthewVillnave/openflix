# Third-party material and license review

OpenFlix's AGPL-3.0-only grant applies to first-party material within the contributors' authority. It does not replace dependency licenses. This is an engineering inventory and compliance review, not a legal certification or a vulnerability audit.

## Pinned components

- **Jellyfin TypeScript SDK 1.0.0**, MPL-2.0. Original [license](third-party/jellyfin-sdk-LICENSE.txt); corresponding source at official commit [1fdc2aefcf963fec84e7eafe15743dafe8c1d26a](https://github.com/jellyfin/jellyfin-sdk-typescript/tree/1fdc2aefcf963fec84e7eafe15743dafe8c1d26a), including SDK/generated-client build configuration. The SDK remains unmodified, separately installed and server-side; no generated DTO implementation was copied into first-party files. Preserve MPL notices and make SDK source available when conveying its executable form. The standard license's Exhibit B text is not itself an applied incompatibility notice; no separate “Incompatible With Secondary Licenses” designation was found in the reviewed package. MPL section 3.3 permits the larger-work combination with AGPL under its conditions; MPL rights and source obligations remain. See the [official MPL FAQ](https://www.mozilla.org/en-US/MPL/2.0/FAQ/).
- **HLS.js 1.7.3**, Apache-2.0. Preserve [original attribution](third-party/hls.js-LICENSE.txt), including Dailymotion and Brightcove-derived portions, and the [full Apache license](third-party/Apache-2.0.txt). Official source: [v1.7.3](https://github.com/video-dev/hls.js/tree/v1.7.3). It is bundled into the browser application; attribution must accompany that distribution, not merely remain in a development node_modules directory.
- **React/React DOM/scheduler**: MIT, retained notices from the resolved packages. Server dependencies include Fastify/Pino/Zod/Axios/better-sqlite3 (MIT) and Argon2 bindings (MIT with bundled native-component notices). SQLite and native sources retain their own embedded notices. Do not infer ownership of native libraries from a JavaScript wrapper's license.
- Tooling includes Apache-2.0, BSD, ISC, MIT/MIT-0, BlueOak-1.0.0, CC0-1.0 and MPL-2.0 packages (including lightningcss). Platform-specific packages vary by build host. The lockfile fixes resolution; the generated installed-package notice inventory records the actual build and includes license/notice files and README attribution where standalone texts are absent. It does not claim to inventory uninstalled architectures.

## Source and asset provenance

The first-party tree was inspected for copied/generated source, attribution markers and assets. Jellyfin-specific code calls SDK operations and normalizes contracts; generated upstream code stays in the dependency. Test-media scripts generate patterns and tones, not household files. There are no committed household media binaries or externally sourced artwork/fonts. Preserve any future upstream source/asset notices rather than applying project headers indiscriminately.

This release distributes source, scripts and container definitions only, not npm packages, executable bundles or registry images. Frozen installation fetches external dependencies; their original licenses and notices remain applicable. The UI build includes the actual installed dependency notices at a fixed legal-asset path. When conveying executable builds, provide the complete corresponding source needed to build/install them, including required non-system dependency source and build scripts; a lockfile alone is not an unconditional substitute for that obligation. Retain source availability for the distribution's required period and the actual versions conveyed.

## Containers and verification tools

Production definitions use Node 24.19.0 Debian bookworm-slim and Nginx 1.30.5 Alpine. Node includes its own third-party notices; Nginx uses its BSD-style license; Debian/Alpine packages each retain their own copyright/license files. Preserve `/usr/share/doc` and other image notices and obtain corresponding package source for any copyleft binaries you redistribute. Base-image tags can be updated upstream; inventory the actual image digest/package versions when distributing an image. This task publishes no images or binaries.

Disposable verification adds Jellyfin 10.11.11, FFmpeg and codecs, Chromium, Playwright and build tools. They are separate test services/tools, not relicensed OpenFlix components. Jellyfin/FFmpeg and codec configuration may impose GPL/LGPL source obligations if their images/binaries are redistributed. Follow their upstream notices and exact build configuration; do not treat the source ZIP as corresponding source for arbitrary third-party images. Generated fixture media are excluded from the release archive.
