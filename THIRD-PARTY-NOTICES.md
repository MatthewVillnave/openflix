# Third-party material and license review

OpenFlix's AGPL-3.0-only grant applies to first-party material within the contributors' authority. It does not replace dependency licenses. This is an engineering inventory and compliance review, not a legal certification or a vulnerability audit.

Original [license](third-party/jellyfin-sdk-LICENSE.txt); the version-specific npm registry metadata identifies upstream revision [8a167e4aedd5a86993c4273fe153d49722233c3b](https://github.com/jellyfin/jellyfin-sdk-typescript/tree/8a167e4aedd5a86993c4273fe153d49722233c3b). - **HLS.js 1.7.3**, Apache-2.0. Preserve [original attribution](third-party/hls.js-LICENSE.txt), including Dailymotion and Brightcove-derived portions, and the [full Apache license](third-party/Apache-2.0.txt). The lockfile fixes resolution; the generated installed-package notice inventory records the actual build and includes license/notice files and README attribution where standalone texts are absent. It does not claim to inventory uninstalled architectures.

## Source and asset provenance

The tested Linux x86-64 candidate's version-exact server and browser package inventory is in [runtime-source-inventory.json](third-party/runtime-source-inventory.json). The separate local `openflix-third-party-material.tar.gz` companion contains the 121 official npm package tarballs listed there, each verified against the lockfile SHA-512 integrity, plus upstream source snapshots identified in its `upstream-manifest.json`. Registry packages can contain generated code or native binaries and are not automatically equivalent to complete corresponding source. In particular, npm metadata for `@node-rs/argon2-linux-x64-gnu@2.2.1` supplies no `gitHead`; the same-version wrapper's source snapshot is included but its exact binary build correspondence remains unproven. The registry also supplies no `gitHead` for `@types/node@24.19.1`, `helmet@8.3.0`, or `toad-cache@3.7.4`. The pinned images' 88 Debian and 71 Alpine installed packages and their recorded source-package metadata are enumerated in [container-system-inventory.json](third-party/container-system-inventory.json); their source packages and exact build inputs have not all been collected. Resolve the applicable items before treating a binary source offer as complete.

The first-party tree was inspected for copied/generated source, attribution markers and assets. Jellyfin-specific code calls SDK operations and normalizes contracts; generated upstream code stays in the dependency. Test-media scripts generate patterns and tones, not household files. There are no committed household media binaries or externally sourced artwork/fonts. Preserve any future upstream source/asset notices rather than applying project headers indiscriminately.

This release distributes source, scripts and container definitions only, not npm packages, executable bundles or registry images. Frozen installation fetches external dependencies; their original licenses and notices remain applicable. The UI build includes the actual installed dependency notices at a fixed legal-asset path. When conveying executable builds, provide the complete corresponding source needed to build/install them, including required non-system dependency source and build scripts; a lockfile alone is not an unconditional substitute for that obligation. Retain source availability for the distribution's required period and the actual versions conveyed.

## Containers and verification tools

Production definitions pin Node 24.19.0 Debian bookworm-slim and Nginx 1.30.5 Alpine by image manifest digest. Node includes its own third-party notices; Nginx uses its BSD-style license; Debian/Alpine packages each retain their own copyright/license files. Preserve `/usr/share/doc` and other image notices and obtain corresponding package source for any copyleft binaries you redistribute. Package versions inside the actual built images must be inventoried; a pinned base image does not pin the build-stage apt repository. This task publishes no images or binaries.

Disposable verification adds Jellyfin 10.11.11, FFmpeg and codecs, Chromium, Playwright and build tools. They are separate test services/tools, not relicensed OpenFlix components. Jellyfin/FFmpeg and codec configuration may impose GPL/LGPL source obligations if their images/binaries are redistributed. Follow their upstream notices and exact build configuration; do not treat the source ZIP as corresponding source for arbitrary third-party images. Generated fixture media are excluded from the release archive.
