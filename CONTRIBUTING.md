# Contributing

Contributions to first-party OpenFlix are submitted under **AGPL-3.0-only**, the same license as the project. Submit only material you have the rights needed to contribute under that license. Preserve third-party copyrights, license texts and notices and identify copied or generated upstream material and its provenance.

No copyright assignment, special commercial privilege or separate contributor contract is required by this guidance. Commercial use is permitted under the standard license. Read [LICENSE](LICENSE), [NOTICE](NOTICE) and [third-party obligations](THIRD-PARTY-NOTICES.md).

Keep changes scoped and tested. Do not edit historical migration SQL, audit artifacts or tags. Do not submit credentials, runtime databases/logs, household media or private audit captures. Use the [verification instructions](docs/milestone-5-verification.md) and document failures honestly. New milestone work requires a separate scope decision; release integration does not authorize federation.

When distributing or serving modifications, offer corresponding source for the actual modified version, preserve legal notices and update the deployment's source link. An upstream release link is not sufficient for a modified or unknown build. See [licensing operations](docs/licensing.md).
